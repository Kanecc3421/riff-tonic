# 微信朋友圈文案

## 短版

做了个 Windows 吉他练习小工具：Riff Tonic。
录一段电脑声音，圈一句 A–B 循环，降速不降调，再用小钢琴对音。乐句存在本地，下次接着练。
一句一句来，先听清，再弹顺。🎸

## 长版

最近把一个吉他练习小工具整理成了桌面版，叫 Riff Tonic。

它做的事情很简单：录下电脑正在播放的声音，或者导入音频；在波形上圈出难点反复播放，慢下来听，音高保持不变。旁边放了节拍器和鼠标钢琴，用来跟拍、核对音高。练过的乐句和设置可以留在本地。

这次把中英文切换和字标也一起做了。Windows 10/11 可用，还是早期版本，暂时没有自动扒谱或自动测 BPM。

希望它能把来回拖进度条的时间，换成多弹几遍的时间。
有练吉他的朋友可以看看，也欢迎把实际练习里不顺手的地方告诉我。

## 长图文字（从上到下）

Riff Tonic
一句乐句，慢一点。

01 / 留下想练的那一句
录制电脑声音，或直接导入音频。

02 / 把难点圈出来
在波形上选出 A–B，循环听、反复练。

03 / 慢下来，音高留住
0.5–2 倍速播放；手动设置节拍与第一拍。

04 / 听一听，再对一对
C2–C5 鼠标钢琴，音量与尾音可调。

05 / 下次接着练
乐句与练习设置保存在本地。

Windows 10/11 · 中英文界面 · v0.8
录制上限10分钟 · 导入上限15分钟
当前不支持自动扒谱、自动 BPM 或 MIDI 输入。
