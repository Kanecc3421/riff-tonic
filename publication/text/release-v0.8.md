# Riff Tonic v0.8

## English

A Windows desktop companion for practicing guitar phrases by ear.

- Capture system playback or import audio with FFmpeg.
- Select an A–B loop, seek, crop / delete a selection, and undo edits.
- Practice at 0.5–2× speed while preserving pitch.
- Set the first beat and BPM manually; use beat snapping and a metronome.
- Check notes on a C2–C5 mouse piano, with separate audio / click / piano levels.
- Save phrases and practice settings locally; restored phrases start paused.
- Switch between English and Simplified Chinese, with a refreshed Riff Tonic wordmark.

**Windows 10/11.** Extract the entire package, then run `RiffTonic/RiffTonic.exe`. Keep its supporting files together.

Capture limit: 10 minutes. Import limit: 15 minutes. No automatic BPM detection, tab generation, AI transcription, or MIDI input in this version. Output capture depends on the selected Windows device; rescan after changing devices.

## 简体中文

面向 Windows 的吉他乐句听音练习工具。

- 录制电脑播放声音，或通过 FFmpeg 导入音频。
- 波形选区 A–B 循环、定位、裁剪、删除与撤销。
- 0.5–2 倍速保调播放。
- 手动设置 BPM 与第一拍，支持节拍吸附和节拍器。
- C2–C5 鼠标钢琴，原音 / 节拍 / 钢琴分别调音量。
- 乐句和练习设置本地保存，恢复时先保持暂停。
- 中英文切换与更新后的 Riff Tonic 字标。

**Windows 10/11。** 完整解压后运行 `RiffTonic/RiffTonic.exe`，保留所有依赖文件。

单次录制最长10分钟，单个文件导入最长15分钟。当前没有自动 BPM、自动六线谱、AI 转写或 MIDI 输入。录音依赖 Windows 输出设备，切换设备后请重新扫描。
